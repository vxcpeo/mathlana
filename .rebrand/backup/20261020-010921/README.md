# Mathlana — website

The Vue 3 front end for [mathlana.si](https://mathlana.si/): *"Math and
cryptography research agents, on Solana."*

Built with **Vue 3**, **Vite 7**, **vue-router 4** and **Tailwind CSS v4**.

## Getting started

```bash
pnpm install
pnpm dev        # http://localhost:5310
pnpm build      # -> dist/
pnpm preview    # http://localhost:4310
```

Both the dev and the preview server proxy `/api/*` to `https://mathlana.si`, so
the live quantum-computer ticker and the market data behave exactly as they do
on the real site. In production you point that route at your own backend (or at
the original origin) — see `vite.config.js`.

## Design system

Everything lives in `src/style.css`: the reference site's own token values,
re-exported to Tailwind through `@theme inline` so they are available as
ordinary utilities.

```html
<div class="rounded-xl border bg-card text-card-foreground">
  <h2 class="headline text-2xl text-foreground">Two threats to your keys</h2>
  <p class="text-sm text-muted-foreground">…</p>
  <span class="font-mono text-[0.95rem] text-brand-text figures">1,282,404,859</span>
</div>
```

* Surfaces — `background`, `card`, `popover`, `muted`, `secondary`, `accent`
* Text — `foreground`, `muted-foreground`, `quiet`, `quiet-text`
* Semantic families — `brand`, `proven`, `caution`, `failed`, `note`, `quantum`,
  each with `-surface`, `-border` and `-text` variants
* Charts — `chart-1` … `chart-5`
* Utilities — `.headline` (Montserrat semibold, `-0.025em`, `line-height: 1.1`),
  `.figures` (tabular numerals), `.scrollbar-none`

Dark mode is class-driven (`.dark` on `<html>`), applied by
`initTheme()` before mount so the first paint is already correct.

Type is self-hosted in `public/fonts`: Montserrat (headings), DM Sans (body),
JetBrains Mono (figures).

## Reading on-chain state

`src/lib/program.js` builds an Anchor `Program` from the checked-in IDL and
exposes the PDA helpers and read functions that mirror the Rust program:

```js
import { fetchChallenges, fetchToken, formatMetric } from "@/lib/program";

const challenges = await fetchChallenges();
const { record, pool, portrait } = await fetchToken(mint);
console.log(formatMetric(record.poolDeposited, 9), "SOL into the pool");
```

The IDL is generated by `../contracts/tools/generate_idl.py` (or by
`anchor build`) and mirrored here. Regenerate both after changing the program:

```bash
python ../contracts/tools/generate_idl.py
cp ../contracts/idl/mathlana.json src/idl/mathlana.json
```

Set the deployed program address in `src/data/onchain.js`:

```js
export const MATHLANA_PROGRAM_ID = "<your deployed program id>";
```

and the RPC in the environment:

```bash
VITE_RPC_ENDPOINT="https://your-rpc.example.com" pnpm build
```

## The launch fee and the split

Both the launch page's copy and the on-chain instructions read from the same
constants in `src/data/onchain.js`:

```js
export const LAUNCH = {
  feeSol: 0.02,                                   // "Launching costs 0.02 SOL…"
  feeShare: {                                     // "Of the token's share of
    aiQuantumPoolBps: 6000,                       //  every trade's fee, locked
    platformBps: 2000,                            //  on chain:"
    creatorBps: 2000,
  },
  workedExample: { tradedUsd: 1000, poolUsd: 1.44, creatorUsd: 0.48 },
};
```

`../contracts/programs/mathlana/src/constants.rs` carries the same numbers.

## Wallet connection

The reference signs in through Privy and launches through pump.fun. This clone
uses the injected Solana providers directly (`window.solana` for Phantom,
`window.solflare` for Solflare) so no third-party script is required; every
signature path fails with a clear message when no wallet extension is present.

## Notes on fidelity

* Copy, section order, spacing, borders, radii and colours follow the reference
  1:1. Numbers shown on the home and challenges pages come from
  `src/data/challenges.js`, which holds the same records the live site renders.
* The engraved line art (`components/art/CardArt.vue`), the quantum-computer
  wordmarks (`components/art/MachineLogo.vue`) and the brand mark were extracted
  from the reference bundle rather than redrawn.
* `Urania` in the hero is the reference's own artwork (`public/brand/`), shown
  light-on-dark in dark mode and ink-on-light in light mode, with the same
  bottom mask.
* The `/exposure` checker runs entirely in the browser: nothing is stored and no
  wallet connects, exactly as the page states.
